# Kempes Kasino

*"Kasino with a K"*

A craps odds calculator built for home games. Pick a bet, set the house rules (odds multiple, field pay, buy/lay vig), click a roll result on the dice-pip picker, and see the payout instantly. Reference tables below show true odds and house edge for every standard casino bet &mdash; line bets, place/buy/lay, one-roll props, hardways, and Big 6/8.

Live site: https://dougfoster68-coder.github.io/kempes-kasino/
